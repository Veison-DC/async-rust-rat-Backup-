# Internationalization (i18n)

The Async Rust RAT application now supports multiple languages through internationalization (i18n).

## Supported Languages

The application currently supports the following languages:

- **English (en)** - Default language
- **Japanese (ja)** - 日本語
- **Simplified Chinese (zh-CN)** - 简体中文
- **Traditional Chinese (zh-TW)** - 繁體中文
- **Korean (ko)** - 한국어

## How to Use

### Changing Language

1. Locate the **language selector** in the top-right corner of the application header
2. Click on the language selector button (shows current language flag)
3. Select your preferred language from the dropdown menu
4. The entire application will immediately switch to the selected language

### Language Persistence

Your language preference is automatically saved in the browser's local storage, so the application will remember your choice the next time you open it.

## Translated Components

The following components have been fully translated:

- **Layout/Navigation**: Sidebar menu items, server controls, and status messages
- **Settings Page**: All configuration options and labels
- **Client Information**: System details, security information, and user data
- **World Map**: Map labels and statistics
- **Window Types**: All window titles and labels

## For Developers

### Adding New Languages

To add a new language:

1. Create a new JSON file in `server/src/i18n/locales/` (e.g., `es.json` for Spanish)
2. Copy the structure from `en.json` and translate all values
3. Import the new translation file in `server/src/i18n/config.ts`
4. Add the language to the resources object
5. Update the language selector in `server/src/components/LanguageSelector.tsx`

### Adding New Translation Keys

To add new translatable text:

1. Add the key to all language files in `server/src/i18n/locales/`
2. Use the `useTranslation` hook in your component:
   ```tsx
   import { useTranslation } from 'react-i18next';
   
   const MyComponent = () => {
     const { t } = useTranslation();
     return <div>{t('mySection.myKey')}</div>;
   };
   ```

### Translation File Structure

Translation files are organized by sections:

- `layout`: Navigation and header elements
- `windowTypes`: Window title translations
- `settings`: Settings page labels and options
- `clientInfo`: Client information labels
- `worldMap`: Map-related text
- `common`: Common UI elements (buttons, messages, etc.)

## Technical Details

- **Library**: react-i18next (React wrapper for i18next)
- **Configuration**: `server/src/i18n/config.ts`
- **Locale Files**: `server/src/i18n/locales/*.json`
- **Language Selector**: `server/src/components/LanguageSelector.tsx`

1. All keys from the English file are present in your translation
2. Translations are accurate and culturally appropriate
3. Technical terms are correctly translated
4. The JSON file is properly formatted

For questions or issues related to translations, please create an issue on GitHub.
